# Near Ease – Find Nearby Services with Ease
    NearEase is a location-based mobile app that helps users discover nearby services such as shops, workshops, charging stations, hospitals, and parking spots — all in one place.

    With an intuitive map interface, NearEase lets you:

    1. 📍 View real-time locations of nearby service points
    2. 🏪 Explore detailed info like opening hours, contact, and available services
    3. 🔍 Search and filter by service type or distance
    4. 🧭 Get navigation directions instantly
    
    Built to make city life simpler, NearEase connects people with essential local services — anytime, anywhere.
